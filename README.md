# 异常开药调查证据室

约定异常开药调查中的材料来源、权限与阶段结论。

## 领域资料

仓库中的 `contracts/context.schema.json` 描述基础资料格式，`fixtures/context.json` 给出可公开使用的示例。代码库只负责读取与校验这些资料，业务服务可沿用相同标识和版本约定。

当前资料反映的事实包括：

- 调查会结合结算、监控、资金和物流信息
- 单条疑点不宜立即打草惊蛇
- 阶段结论需要保留采用的证据

## 受控证据室

`src/evidence_room.py` 实现调查组的受控证据室：

- **材料登记**：按调查假设登记对象关系；每份材料记录取证授权、来源、取得时间、校验摘要（SHA-256）与可使用范围，登记必须落在有效授权的来源、范围与有效期内。
- **候选对应**：视频片段与结算记录等材料间可先建立候选对应，须由提案人以外的人员复核后才进入身份合并视图，系统不会自动合并身份。
- **决定日志**：线索升级、补充授权、证据失效、跨部门借阅、并行分析等全部写入仅可追加、哈希链式校验的日志，条目为不可变对象，可整体校验是否被覆盖或篡改。
- **阶段化可见**：案件按“线索核查 → 初步调查 → 正式调查 → 结案”只能向前推进；案情未到相应阶段时，各小组只能看到履职所需的材料种类，负责人始终全量可见。
- **阶段结论**：负责人提交结论时冻结所用材料的版本与摘要；报告区分已相互印证的事实（至少两个独立来源支持）、仍待核的关联，并列出每份材料后来的移交记录与版本状态。
